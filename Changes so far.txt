4. Same-language response behavior
- server/index.js detects response language from the user’s latest question.
- Japanese, German, French, Spanish, English are handled.
- Backend passes Required response language to Bedrock.
- Bedrock prompt says:
  - answer in Required response language
  - do not ask user to switch to English
  - preserve company/product terms
- Company-specific terms should not be translated:
  Vera, Forever Living, Forever Living Products, FLP, FBO, FPC, IDS, Knowledge Base, product names, document names, URLs, emails.

- Cards should include:
  - image
  - product name
  - category
  - price
  - Why this? description
  - Buy Now link
  - cart icon link

- Buy Now and cart icon should open productUrl/product_url.

8. Startup issue after catalog patch
When running npm run server, this error appeared:
- Some JSON files contain invalid JSON with:
  "price": NaN
- Node JSON.parse fails on NaN.
- Also productCatalogByName was created before normalizeProductName existed.

Fix script created:
C:\Users\KRISH\Documents\Codex\2026-05-14\files-mentioned-by-the-user-forever\fix-enterprise-chatbot-catalog-startup.ps1

It does:
- Moves productCatalogByName creation after normalizeProductName.
- Sanitizes catalog JSON by replacing:
  : NaN
  with:
  : null
before JSON.parse.

Run:

Then:
cd C:\Users\KRISH\enterprise-chatbot
